# 🛒 Walmart Data Analysis | SQL + Python + Power BI

An end-to-end **Data Analysis Project** using **Python, SQL (MySQL), and Power BI** to analyze Walmart sales data and generate actionable business insights.

---

## 🚀 Tech Stack

- 🐍 Python
- 🗄️ MySQL
- 📊 Power BI
- 📈 Pandas & NumPy
- 🔗 SQLAlchemy
- 📥 Kaggle API
- 💻 VS Code

---

## 📌 Project Workflow

### 1️⃣ Environment Setup
- Configure VS Code
- Organize project folders

### 2️⃣ Download Dataset
- Download using Kaggle API
- Store in `data/`

### 3️⃣ Data Exploration
- Inspect data
- Check data types
- Summary statistics

### 4️⃣ Data Cleaning
- ✅ Remove duplicates
- 🧹 Handle missing values
- 🔄 Fix data types
- 💲 Format currency values

### 5️⃣ Feature Engineering
- ➕ Create **Total Amount**
- 📊 Prepare data for SQL & BI analysis

### 6️⃣ Database Integration
- 🐬 Load data into MySQL

### 7️⃣ SQL Analysis
Solve business problems such as:
- 💰 Revenue Trends
- 🏪 Branch Performance
- 📦 Best-Selling Categories
- 💳 Payment Method Analysis
- ⏰ Peak Shopping Hours
- 📈 Profit Margin Analysis

### 8️⃣ 📊 Power BI Dashboard
Build an interactive dashboard featuring:
- 📌 KPI Cards (Revenue, Profit, Orders)
- 🌍 Sales by City & Branch
- 📦 Category & Product Performance
- 💳 Payment Method Distribution
- ⭐ Customer Ratings Analysis
- 📅 Monthly Sales Trend
- 🎯 Interactive Filters (Branch, City, Category, Date)

### 9️⃣ Documentation
- 📄 README
- 📒 Jupyter Notebook
- 🗂 SQL Scripts
- 📊 Power BI Dashboard (.pbix)
- 🌐 GitHub Repository
