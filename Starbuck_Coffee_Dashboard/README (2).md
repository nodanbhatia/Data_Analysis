# Starbucks-Sales-Store-Analytics-Dashboard

An interactive Power BI dashboard built to analyze Starbucks beverage nutrition data and global store locations. The project combines data cleaning, exploratory analysis, visualization, and business insights to understand product characteristics and Starbucks' worldwide store distribution.

📊 Project Overview

This project analyzes Starbucks data using Microsoft Power BI to create an interactive dashboard covering:

Beverage categories and product offerings
Calories, caffeine, sugar, fat, protein, and other nutritional values
Beverage preparation types and sizes
Starbucks store distribution across countries and cities
Store ownership types such as Licensed stores
Geographic distribution of Starbucks locations
Key patterns and insights from the datasets

🔍 Key Insights

The dashboard helps identify:

Which Starbucks beverage categories have higher calorie and sugar values
Products with high or low caffeine content
Differences in nutritional values across beverage types
Countries and regions with a larger Starbucks presence
Distribution of Starbucks stores across different ownership types
Geographic patterns in Starbucks' global expansion
🎯 Project Objective

The main objective of this project is to transform raw Starbucks datasets into an interactive business intelligence dashboard that makes complex data easier to understand and supports data-driven analysis.
